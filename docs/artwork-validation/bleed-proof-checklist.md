# Full-bleed proof checklist

For a printed proof of a full-bleed coloring interior (a `-bleed` profile). Fill it
with the copy in hand, in daylight, beside `interior.pdf` in Studio's Print proof with
the **Trim line** and **Bleed** overlays on, and the Pages crop preview of the same
pages. "Not checked" is an honest answer. Nothing here is filled in by software.

Proof details: profile ______ paper ______ order date ______ received ______
interior.pdf SHA-256 (first 12) ______ cover.pdf SHA-256 (first 12) ______

Scale: good / acceptable / poor / not checked. KDP allows some variance in where the
cut falls; record the largest shift you measure (in mm) rather than a verdict.
